# План Развития Baku PDF (Версии v1.1.0 – v1.5.0)

В этом документе представлен детальный аудит базовых функций, доступных в **Baku PDF v1.0.0**, а также структурированный технический план запланированных улучшений, оптимизаций и архитектурных модулей, распределённых по версиям с **v1.1.0 по v1.5.0**. Каждый этап релиза спроектирован измеримым, проходит поэтапное тестирование и строго сохраняет фундаментальные принципы приложения:

Ключевые архитектурные принципы:
- **100% Офлайн (Local-First)**: Исключительно локальная обработка данных на вашем устройстве без облачных серверов.
- **Абсолютная Конфиденциальность**: Полное отсутствие телеметрии, трекеров и передачи данных во внешние сети.
- **Минимальное Потребление Ресурсов**: Мгновенный запуск и низкое потребление оперативной памяти (~50–80 МБ ОЗУ).
- **Минималистичный Flat 2D Дизайн**: Функциональный, лаконичный и не отвлекающий интерфейс.
- **Строгое Соответствие Стандартам**: Точное следование правилам оформления академических диссертаций и делопроизводства.

## 2. План Релиза Версии 1.1.0 (Вкладки Нескольких Документов и Эффективность)

Этап **v1.1.0** ориентирован на многозадачную работу с несколькими документами и локальное сжатие PDF-файлов:

### 2.1. Панель Вкладок Нескольких Документов (Multi-Document Tab Bar)
- **Назначение и Преимущества**: Устраняет необходимость постоянного переключения между окнами операционной системы (`Alt+Tab` / `Cmd+`) при одновременной работе с черновиком, правками научного руководителя и методическими указаниями.
- **Эргономичное Размещение**: Расположена непосредственно **под панелью Ribbon Toolbar и прямо над линейкой и холстом редактирования**.
- **Визуальное Оформление Flat 2D**: Компактная панель (высота 30–32 px); активная вкладка на чистом белом фоне (`#FFFFFF`) с синей акцентной полосой сверху (`#2563EB`); неактивные вкладки светло-серые (`#F3F2F1`) с усечением длинных имен.
- **Адаптивная Горизонтальная Прокрутка**: Пропорциональное отображение до 5 документов; плавная горизонтальная прокрутка колесиком мыши/трекпадом и кнопки-стрелки `<` и `>` при открытии более 5 документов.
- **Изоляция Состояния и Безопасность**: Отдельная история отмены/повтора (`Ctrl+Z` / `Ctrl+Y`), индикатор несохраненных правок (синяя точка) и предупреждающий диалог перед закрытием вкладки.
- **Оптимизация Оперативной Памяти (RAM)**: Фоновые вкладки хранятся в виде легковесных структур Delta JSON без монтирования элементов DOM в дереве страницы, сохраняя низкое потребление ОЗУ (~50–80 МБ).
- **Горячие Клавиши**: `Ctrl+Tab` — следующая вкладка, `Ctrl+Shift+Tab` — предыдущая вкладка, `Ctrl+W` — закрыть текущую вкладку.

### 2.2. Офлайн-Компрессор Файлов PDF (Offline PDF Compressor)
- Локальное уменьшение размера PDF на Rust без потери четкости векторного текста.
- Предустановленные профили: до 500 КБ (госслужба и гранты), до 1 МБ (университетские репозитории), до 2 МБ и ручной выбор разрешения (150, 96, 72 DPI).
- Наглядная оценка размера до и после сжатия перед сохранением.

## 3. План Релиза Версии 1.2.0 (Академические Стандарты и Научная Типографика)

Этап **v1.2.0** внедряет стандарты оформления диссертационных работ и математические формулы:

### 3.1. Автоматическая Двойная Нумерация Страниц Диссертаций
- Первая страница каждой новой главы (с заголовком главы) нумеруется **внизу по центру**; последующие страницы главы автоматически нумеруются в **правом верхнем углу**.
- Независимый сброс нумерации по разделам.

### 3.2. Математические Формулы KaTeX Офлайн
- Полностью встроенный локальный движок KaTeX. Вставка формул в строке (`Inline Math`) и отдельными блоками (`Block Equation`).
- Автоматическая нумерация уравнений у правого края: `(1.1)`, `(1.2)`.

### 3.3. Расширенное Оформление Научных Таблиц (Стиль Booktabs)
- Горизонтальное и вертикальное объединение ячеек.
- Академические границы без вертикальных линий (толстая верхняя линия, тонкая линия заголовка, толстая нижняя линия).
- Выравнивание по десятичному разделителю в числовых столбцах и автоматическое повторение шапки таблицы при переносе на новую страницу.

### 3.4. Вертикальная Линейка и Абзацные Отступы
- Ползунки на горизонтальной линейке для отступа первой строки (красная строка) и висячего отступа (список литературы).
- Вертикальная линейка слева для визуальной настройки верхнего и нижнего полей.

### 3.5. Офлайн-Проверка Орфографии и Языковые Рекомендации
- Встроенный локальный словарь, контекстные исправления по правому клику мыши и автоматические переносы слов (*hyphenation*) для аккуратного выравнивания по ширине.

### 3.6. Автоматизация Структуры Документа
- Динамическое оглавление с отточиями и обновлением в один клик.
- Автоматические списки таблиц и иллюстраций с актуальными номерами страниц.
- Офлайн-менеджер цитирования с поддержкой BibTeX (`.bib`), ГОСТ, APA 7, IEEE, Harvard и Vancouver.

## 4. План Релиза Версии 1.3.0 (Полная Кроссплатформенная Дистрибуция и Навигация)

Этап **v1.3.0** предоставляет готовые установщики для Windows и Linux и навигационную панель:

### 4.1. Дистрибуция для Microsoft Windows
- Мастер установки NSIS (`.exe`) для 64-бит и ARM64 на Windows 10 и 11 с регистрацией расширения `.baku`.
- Портативная версия без установки (`Baku_Portable.exe`) для лабораторий и закрытых сред.
- Публикация в официальном репозитории Windows Package Manager (`winget install Baku.BakuPDF`).

### 4.2. Дистрибуция для Linux
- Универсальный автономный файл `AppImage` для Ubuntu, Fedora, Arch Linux, Debian и openSUSE.
- Нативный пакет `.deb` для Debian/Ubuntu с готовыми зависимостями.
- Поддержка Flatpak (Flathub) и пакет в AUR (`baku-bin`).

### 4.3. Расширенная Поддержка macOS
- Установка через Homebrew Cask (`brew install --cask baku-pdf`).
- Официальная цифровая подпись Apple Developer ID и нотаризация для запуска без предупреждений Gatekeeper.

### 4.4. Боковая Панель Навигации по Документу
- Складная панель слева: иерархическое дерево заголовков (главы и подглавы), вертикальные миниатюры страниц и результаты поиска.

## 5. План Релиза Версии 1.4.0 (Офлайн-Утилиты PDF и Безопасность Документов)

Этап **v1.4.0** расширяет арсенал работы с PDF и защитой персональных данных:

### 5.1. Цифровая Подпись и Факсимиле Офлайн
- Рисование подписи пером/курсором или загрузка прозрачных изображений PNG с позиционированием перетаскиванием.
- Пакетная подпись по фиксированным координатам на нескольких страницах и штамп даты.

### 5.2. Очиститель Метаданных Документов
- Удаление имен авторов, путей к файлам на компьютере и меток времени для анонимного рецензирования (*Blind Review*).

### 5.3. Визуальный Органайзер Страниц
- Сетка миниатюр для изменения порядка страниц перетаскиванием, быстрого удаления и вставки чистых страниц или страниц из других PDF.

### 5.4. Текстовые Водяные Знаки Офлайн
- Диагональное или горизонтальное нанесение водяных знаков (`ЧЕРНОВИК`, `КОНФИДЕНЦИАЛЬНО`, `ОФИЦИАЛЬНАЯ КОПИЯ`) с регулятором прозрачности.

### 5.5. Защита и Шифрование PDF Паролем
- Локальное шифрование AES-256 с паролем на открытие и паролем разрешений (запрет печати и копирования текста).

### 5.6. Внешняя Нумерация Страниц (Нумерация Бейтса)
- Простановка номеров страниц на готовые сторонние PDF-файлы с настраиваемыми префиксами.

## 6. План Релиза Версии 1.5.0 (Вершина Экосистемы и Производительность Больших Документов)

Этап **v1.5.0** представляет собой кульминацию развития экосистемы Baku PDF:

### 6.1. Портативные Пакеты Шаблонов (.bakutpl)
- Экспорт пользовательских шаблонов в переносимые файлы `.bakutpl` и их прямой импорт на других устройствах.

### 6.2. Расширенная Коллекция Специализированных Шаблонов
- Двухколоночные научные журналы и формат конференций IEEE.
- Заявки на гранты, отчеты по производственной практике и диссертационные проекты.
- Официальные административные документы (приказы, распоряжения, акты приема-передачи).

### 6.3. Бесконечный Виртуальный DOM-Рендеринг (500+ Страниц)
- Отрисовка страниц только в видимой области экрана (*viewport*), обеспечивая задержку ввода менее 8 мс даже при редактировании сотен страниц.

### 6.4. Нативный Движок Экспорта PDF на Чистом Rust
- Прямая генерация векторных файлов с помощью Rust (`printpdf`/`lopdf`) и встраивание подмножества шрифтов, снижающее вес файла на 60%.

### 6.5. Полная Адаптивная Темная и Светлая Тема
- Высококонтрастная темная тема стандарта WCAG AAA с возможностью отображения белого или инвертированного листа и синхронизацией с ОС.

### 6.6. Режим Фокусировки (Zen) и Двухстраничный Разворот
- Мгновенное скрытие интерфейса (`F11` / `Cmd+Shift+F`) и отображение двух страниц рядом на широких мониторах.

### 6.7. Импорт Word (.docx) и Экспорт в Стандартные Форматы
- Локальный синтаксический анализ Word-файлов с сохранением структуры и экспорт в `.docx`, обычный текст (`.txt`) и Markdown (`.md`).

### 6.8. Обновление Спецификации Формата .baku (v2.0)
- Контейнер бинарных вложений со сжатием без потерь для графики высокого разрешения и полная обратная совместимость с v1.0.0.

### 6.9. Периодическое Автосохранение и Восстановление Сессии
- Фоновое сохранение каждые 60 секунд с предложением восстановления при аварийном завершении и локальные снимки версий.
