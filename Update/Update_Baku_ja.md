# Baku PDF ロードマップ (v1.1.0 – v1.5.0 段階的リリース計画)

本書は、**Baku PDF v1.0.0** の機能基盤を踏まえ、**v1.1.0 から v1.5.0 にかけて段階的にリリースされる** 新機能群、性能改善、モジュール拡張計画をまとめた開発パイプラインです。この段階的リリースでは、高度な学術文書執筆、完全オフラインPDF追加ツール、マルチプラットフォーム対応（Windows、macOS、Linux）、および大規模原稿の高速描画に重点を置いています。

Baku PDFの基本方針：
- **100% オフライン（ローカルファースト）**: すべての文書処理はローカルPC上で完結し、クラウドサーバーを一切使用しません。
- **完全なプライバシー保護**: トラッキング、テレメトリ、外部通信は皆無です。
- **超軽量リソース設計**: 高速起動と省メモリ消費（約50〜80MB RAM）。
- **ミニマルな2Dフラットデザイン**: 集中を妨げないクリーンで機能的なUI。
- **標準規格の徹底遵守**: 学術論文および公的文書の厳格な書式基準に適合。

## 2. 文書エディタと高度な学術タイポグラフィ

### 2.1. オフライン KaTeX 数式・記号入力
- アプリケーションに完全内蔵されたオフライン KaTeX パーサー。
- 文中インライン数式および独立した中央揃えブロック数式の挿入。
- 章ごとの右端自動数式番号採番：`(1.1)`、`(1.2)`。
- 行列、微分積分、物理・化学の各種学術記号の入力支援。

### 2.2. インタラクティブルーラー拡張：段落インデントと垂直ルーラー
- 水平ルーラーのマーカー拡張：
  - **1行目インデントマーカー**: 段落の字下げ幅を設定（例: 1cm または 1.27cm）。
  - **ぶら下げインデントマーカー**: 2行目以降の字下げ幅を設定（APA・IEEE・参考文献リスト標準）。
- 編集キャンバス左側の**垂直ルーラー（縦定規）**:
  - 実寸センチメートル単位のページ高さ測定。
  - ドラッグ操作で上下マージンを直感的に直接調整。

### 2.3. 高度な学術用テーブル（表作成）
- 水平セル結合（列結合）および垂直セル結合（行結合）。
- 学術論文標準スタイル（Booktabs形式）：縦方向の罫線を排除し、上下の太線とヘッダー下の細線のみで構成。
- 数値列の小数点位置自動揃え。
- ページをまたぐ表のヘッダー行自動反復表示（Repeat Header Row）。
- 表タイトルの自動採番：`表 1.1: 実験結果一覧`。

### 2.4. オフラインスペルチェックとハイフネーション
- 内蔵辞書によるタイプミス検出。
- 未登録単語への控えめな赤色波線表示。
- 右クリックメニューからの置換候補表示。
- 両端揃え（Justify）における不自然な単語間隔を防ぐ自動ハイフネーション。

## 3. 学術文書構造の自動管理

### 3.1. 論文用2ポジションページ番号規則
- 学術論文の標準規定に準拠：
  - 各章の第1ページ（章題があるページ）は**下部中央**に番号配置。
  - 同一章内の2ページ目以降は**右上隅**に自動切替配置。
- 前後の章に影響を与えない独立セクション採番機能。

### 3.2. 動的自動目次生成（Auto Table of Contents）
- 見出し構造（見出し1〜3）に基づく目次の一括自動生成。
- 項目名とページ番号を美しくつなぐリーダー点線（Dot Leaders）の自動配置。
- ページズレや本文改訂時にワンクリックで反映できる全体更新機能。

### 3.3. 図目次・表目次の動的生成
- 本文中の図キャプション・表キャプションを自動検出。
- リアルタイムでページ番号と連動する図一覧・表一覧ページを生成。

### 3.4. オフライン引用・参考文献マネージャー
- 手動入力および BibTeX（`.bib`）・RIS ファイルからのインポート。
- APA 7th、IEEE、Harvard、Vancouver 各種引用形式の自動適用。
- 文末における参考文献リストのアルファベット順・番号順自動ソート生成。

## 4. オフラインPDF拡張ツールの拡充

既存の4ツールに加え、v1.5 では以下の6つのオフラインツールを追加します：

### 4.1. オフラインPDF圧縮ツール
- Rustによる最適化処理で文字の鮮明さを保ちながらファイルサイズを縮小。
- ワンクリックプリセット：500KB以下、1MB以下、2MB以下、カスタム解像度指定（150/96/72 DPI）。
- 保存前の容量削減前後の比較プレビュー表示。

### 4.2. オフライン電子署名・押印ツール
- マウス／ペンによる手書き署名または透過PNG画像の読み込み。
- 任意のページへドラッグ＆ドロップで配置可能なリアルタイムプレビュー。
- 複数ページへの一括座標指定押印機能。
- 日付印・確認印のオフライン押印。

### 4.3. パスワード保護とAES-256暗号化
- 閲覧用パスワードによる強固なローカルAES-256暗号化。
- 印刷・テキストコピー・注釈変更を個別に制限する権限パスワード設定。
- 正当な所有者向けのオフライン保護解除機能。

### 4.4. 視覚的ページ並べ替えオーガナイザー
- 全ページのサムネイルグリッド一覧表示。
- ドラッグ＆ドロップによるページ順序の直感的入れ替え。
- 特定ページの削除、白紙ページの挿入、他PDFからのページ結合。

### 4.5. ベイツ番号付与・外部PDFノンブル印字
- ページ番号のない外部PDFへの連番印字。
- 配置指定：右上、右下、中央下。
- 接頭辞設定（例: `別紙 1/10 ページ`、`番号 1`）。

### 4.6. オフライン透かし（ウォーターマーク）ツール
- 斜め（45度）または水平の透かし文字付与。
- 定型文プリセット：`下書き`、`極秘`、`原本控`、`SAMPLE`。
- 透明度、フォント、文字色、適用ページ範囲の細かな制御。

## 5. 標準テンプレートコレクションの拡充

### 5.1. 学術ジャーナル・学会論文
- **査読論文ジャーナル形式（2カラム組版）**: 全幅タイトル、日英要約（Abstract）、IMRAD標準構成。
- **IEEE国際学会論文形式**: 指定余白、Times New Roman 10pt/8pt、2カラム図表配置。

### 5.2. 大学・研究助成金文書
- **学生研究助成・コンペティション申請書**: 承認欄、標準積算予算表、スケジュール表。
- **インターンシップ・学外実習報告書**: 週間日誌、実習先概要、総合所見。
- **大学院修士・博士論文研究計画書**: 詳細な研究手法、理論的枠組み、仮説検証。

### 5.3. 官公庁・公的機関文書
- **事務連絡・出張命令書**: 公用文書ヘッダー、発信番号、業務指示。
- **決定通知書・訓令**: 前文、根拠規定、決定事項。
- **検収・引渡報告書**: 立会人署名欄付きの正式受領書式。

### 5.4. 独立テンプレートパッケージの書き出し/読み込み (.bakutpl)
- 自作のカスタムテンプレートを単一のポータブルファイル `.bakutpl` としてエクスポート。
- 他のPCのBaku PDFへそのままインポート可能。

## 6. マルチプラットフォーム対応とバイナリ配布

### 6.1. Windows 環境への配布
- **NSISインストーラー (`.exe`)**: 64bit (`x64`) および ARM64 対応、スタートメニュー・ショートカット・`.baku` 関連付け完備。
- **ポータブル版 (`Baku_Portable.exe`)**: 管理者権限不要でUSB等から即時起動可能。
- **Microsoft パッケージマネージャー (`winget`)**: 公式リポジトリ登録。

### 6.2. Linux 環境への配布
- **万能型 `AppImage`**: 依存関係を内包した単一ファイル配布。
- **Debian / Ubuntu 向けパッケージ (`.deb`)**: ネイティブ依存を満たしたバイナリ。
- **Flathub および Arch AUR**: サンドボックス版 Flatpak および `baku-bin`。

### 6.3. macOS 環境の高度な配布
- **Homebrew Cask**: ターミナルから `brew install --cask baku-pdf` で導入可能。
- **Appleコード署名と公証**: Gatekeeperの警告なしで起動できる正規署名。

## 7. コアアーキテクチャ・性能・大容量文書処理

### 7.1. 仮想DOMページレンダリング
- 画面表示中のページおよび前後1〜2ページのみを選択的にレンダリング。
- 500ページを超える長大な論文や書籍でもメモリ消費量を平準化。
- タイピング時の入力遅延を常に8ミリ秒未満に維持。

### 7.2. 純Rust製ネイティブベクターPDF出力エンジン
- WebViewの印刷機能に加え、Rust製ネイティブライブラリ（`printpdf`、`lopdf`）を採用。
- 選択・検索可能な文字データを維持しつつ、PDF容量を最大60%軽量化。
- 本文で使用されている文字のみを埋め込む自動フォントサブセット処理。

### 7.3. 60秒自動保存とクラッシュセッション復元
- 60秒ごとにローカルの保護領域へ自動バックアップ。
- 不意の電源切断時も次回起動時に即座に復元ダイアログを表示。
- 15分前、30分前、60分前の状態へロールバック可能なローカル世代履歴。

## 8. ユーザーインターフェース・ナビゲーション・アクセシビリティ

### 8.1. アウトライン＆サムネイルサイドバー
- 左側に開閉可能なサイドバーを設置：章立てツリー、ページ縮小一覧、検索一致箇所のプレビュー。

### 8.2. 適応型ダークモード／ライトモード
- WCAG AAA基準の高コントラスト設計。
- 白い紙面を保つ印刷重視モードと、夜間の目の負担を抑える黒白反転モード。
- OSの外観モードとの自動同期。

### 8.3. 集中執筆用 Zen モード
- `F11` または `Cmd+Shift+F` で全メニューとツールバーを非表示にし、原稿用紙のみに集中。

### 8.4. 見開き2ページ表示
- ワイド画面モニターに適した横並びの2ページ同時表示。

### 8.5. 複数文書タブバー（Multi-Document Tab Bar）
- **目的と作業効率の向上**:
  - 複数文書を参照しながらの執筆時におけるOSのウィンドウ切替（Alt+Tab / Cmd+`）を撤廃。
  - 単一ウィンドウ内で複数の `.baku` 文書を同時に開き、スムーズに往復編集。
- **人間工学に基づいた配置位置**:
  - **リボンツールバーの直下、定規と執筆キャンバスの直上**に配置。
  - 上から下への自然な視線・操作順序：ツール選択 -> タブ選択 -> 本文編集。
  - 下部ステータスバーを混雑させることなく、ウィンドウの全横幅を有効活用。
- **2Dフラットデザインの視覚的洗練**:
  - 高さ30〜32pxの省スペースなスリムタブバー。
  - **アクティブタブ**: 白地背景（`#FFFFFF`）が定規・キャンバスとシームレスに結合、上端に明瞭なアクセント青線（`#2563EB`）、太字タイトル、閉じる `x` ボタン、未保存表示。
  - **非アクティブタブ**: 落ち着いたニュートラルグレー（`#F3F2F1`）。
  - 長いファイル名の省略表示（ellipsis）と右端の新規作成 `+` ボタン。
- **水平スクロールとナビゲーション**:
  - 1〜5個の文書までは等幅・均等配置。
  - 5個を超える場合はトラックパッドやマウスホイールでスムーズに左右スクロール。
  - タブが溢れた際は左右に補助移動ボタン `<` および `>` を自動表示。
- **状態の完全分離とデータ保護**:
  - タブごとに独立した Delta JSON モデル、スクロール位置、カーソル位置を保持。タブ切替時に1ページ目に戻されることはありません。
  - 元に戻す（`Ctrl/Cmd+Z`）・やり直し（`Ctrl+Y` / `Cmd+Shift+Z`）の履歴をタブごとに完全分離。
  - 未保存の変更がある場合は青丸または `*` で明示し、未保存状態で閉じる際は保存確認を表示。
- **メモリ消費の最小化**:
  - 非アクティブなタブはメモリ上に軽量なデータ構造として保持し、不要なDOM要素を生成しません。

## 11. 段階的リリースマイルストーンと優先度マトリクス (v1.1.0 – v1.5.0)

### 11.1. 段階的リリースマイルストーン一覧

| リリース版 | 主要フォーカス | 搭載予定モジュール | 予定時期 |
