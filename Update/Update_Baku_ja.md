# Baku PDF 更新ロードマップ (バージョン v1.1.0 – v1.5.0)

本書は、**Baku PDF v1.0.0** で提供されている基本機能の検証状況と、**v1.1.0 から v1.5.0** にかけて段階的にリリースされる新機能、性能最適化、および設計拡張計画をバージョンごとに整理した公式技術ドキュメントです。各リリース段階は測定可能かつ段階的にテストされ、アプリケーションの根本思想を厳格に維持します：

基本設計原則：
- **100% オフライン動作 (ローカルファースト)**: クラウドサーバーを介さず端末内ですべての処理を完結。
- **完全なプライバシー保護**: 利用状況のトラッキング、テレメトリ送信、外部通信は一切非搭載。
- **軽量・低リソース消費**: 高速起動と省メモリフットプリント (~50–80 MB RAM) を実現。
- **ミニマルなフラット 2D デザイン**: 作業の集中を妨げないシンプルで実用的なデスクトップ UI。
- **厳格な書式標準準拠**: 大学の学位論文や公的文書の執筆基準に忠実に対応。

## 2. リリース計画 バージョン 1.1.0 (複数文書タブと作業効率化)

**v1.1.0** マイルストーンでは、並行執筆の効率向上と出力PDFの完全ローカル圧縮機能に特化します：

### 2.1. 複数文書タブバー (Multi-Document Tab Bar)
- **目的と作業メリット**: 参照資料（章の下書き、指導教員の修正指示、執筆ガイドライン）を行き来する際の `Alt+Tab` 切り替えを不要にし、同一ウィンドウ内で複数の `.baku` 文書を同時並行で編集可能にします。
- **人間工学に基づく配置位置**: リボンツールバー直下、ルーラーおよびエディターキャンバスの直上に配置し、画面幅を100%活用します。
- **視覚デザイン (フラット 2D)**: 高さ 30-32 px のスリムなタブバー。アクティブタブは白背景 (`#FFFFFF`) に上部ブルーストライプ (`#2563EB`)、非アクティブタブは中間グレー (`#F3F2F1`) で長文タイトルの省略表示に対応。
- **適応型水平スクロール**: 1～5文書までは均等幅で並列表示。6文書以上ではトラックパッドやホイールによる滑らかな水平スクロールと、オーバーフロー時に自動出現する左右ナビゲーションボタン `<` および `>` を装備。
- **状態の完全分離と安全管理**: タブごとに独立した Delta JSON 構造、スクロール位置、カーソル位置、元に戻す/やり直し履歴 (`Ctrl+Z` / `Ctrl+Y`) を保持。未保存インジケーター（青色の点）と閉じる際の安全確認ダイアログを搭載。
- **メモリ効率化 (RAM)**: 背景タブはDOM要素を展開せず、メモリ上に軽量なDeltaデータとして保持。キャンバスにはアクティブ文書のみがマウントされるため、~50-80 MB の低消費メモリとゼロ遅延を維持。
- **キーボードショートカット**: `Ctrl+Tab` で次タブへ移動、`Ctrl+Shift+Tab` で前タブへ移動、`Ctrl+W` でタブを閉じる。

### 2.2. オフラインPDFファイル圧縮ツール (Offline PDF Compressor)
- サーバーを介さず Rust ネイティブ処理でPDFサイズを削減。テキストの鮮明さを保ちながら画像リサンプリングを実施。
- 即時ターゲットプリセット: 500 KB以下（採用応募・奨学金申請）、1 MB以下（大学学術リポジトリ）、2 MB以下、および手動DPI設定（150, 96, 72 DPI）。
- 保存前の圧縮前後ファイルサイズプレビュー表示。

## 3. リリース計画 バージョン 1.2.0 (学術標準と科学タイポグラフィ)

**v1.2.0** マイルストーンでは、論文執筆基準の厳格な適用と数式・学術表機能を追加します：

### 3.1. 学位論文用2ポジション自動ページ番号規則
- 各章の第1ページ（章タイトル記載面）は**下部中央**、章内の継続ページは**右上隅**へ自動振り分け配置。
- 前セクションの番号体系を崩さないセクションごとの独立番号リセット。

### 3.2. オフライン KaTeX 数式表記エンジン
- 100% オフライン同梱の KaTeX エンジン。行内数式 (`Inline Math`) および独立数式ブロック (`Block Equation`) の挿入。
- 章ごとの数式右端自動番号付け: `(1.1)`, `(1.2)`。

### 3.3. 高度な学術表フォーマット (Booktabs スタイル)
- セルの水平・垂直結合。
- 縦罫線を排した学術論文仕様の罫線（上部太線、ヘッダー細線、下部太線）。
- 数値列の小数点位置揃えと、ページ跨ぎ時の表見出し行の自動繰り返し表示。

### 3.4. 垂直ルーラーと段落インデント制御
- 水平ルーラー上の1行目インデントマーカーおよびぶら下げインデントマーカー（参考文献リスト用）。
- 左側の垂直ルーラーによる実ページ高の測定と、上下余白のドラッグ調整。

### 3.5. オフラインスペルチェックと執筆支援
- 内蔵ローカル辞書による誤字検出、右クリックでの語彙提案、両端揃え段落での不自然な空白を防ぐ自動ハイフネーション処理。

### 3.6. 学術文書構造の自動生成
- 見出し階層に基づく目次のワンクリック生成とリーダー線（点線）の自動調整。
- ページ番号と連動する図目次・表目次のリアルタイム更新。
- BibTeX (`.bib`) 読み込み対応のオフライン引用・参考文献管理ツール (APA 7, IEEE, Harvard, Vancouver)。

## 4. リリース計画 バージョン 1.3.0 (マルチプラットフォーム完全配布とナビゲーション)

**v1.3.0** マイルストーンでは、Windows および Linux への正式配布と文書ナビゲーションを拡充します：

### 4.1. Microsoft Windows 向け配布
- Windows 10/11 向け x64/ARM64 対応 NSIS インストーラー (`.exe`)（スタートメニュー、デスクトップ、`.baku` 関連付け）。
- 管理者権限不要のポータブル版 (`Baku_Portable.exe`)。
- 公式 Windows パッケージマネージャーへの登録 (`winget install Baku.BakuPDF`)。

### 4.2. Linux 向け配布
- Ubuntu、Fedora、Arch Linux、Debian、openSUSE 等で動作する単一実行ファイル `AppImage`。
- 依存関係を完備した Debian/Ubuntu 向けネイティブパッケージ (`.deb`)。
- Flatpak (Flathub) マニフェストおよび AUR (`baku-bin`) パッケージ。

### 4.3. macOS 向け高度な配布
- Homebrew Cask によるコマンドインストール (`brew install --cask baku-pdf`)。
- Apple Developer ID 署名と公証（Notarization）による Gatekeeper 警告なしの起動。

### 4.4. 文書構造ナビゲーションサイドバー
- 左側の折りたたみ式パネル。見出し階層ツリー（章と節の即時ジャンプ）、ページサムネイル垂直一覧、検索結果一覧。

## 5. リリース計画 バージョン 1.4.0 (オフラインPDFユーティリティと文書セキュリティ)

**v1.4.0** マイルストーンでは、PDFユーティリティ群の拡充と機密保護機能を追加します：

### 5.1. オフライン電子署名および捺印
- マウス/ペンによる手書き署名入力、透過PNG画像の読み込みとドラッグ＆ドロップ配置。
- 複数ページへの固定座標一括署名と日付スタンプ。

### 5.2. 文書メタデータ消去ツール (ブラインドレビュー用)
- 外部公開前に著者名、PC環境名、編集履歴タイムスタンプを消去し、学術査読の二重盲検審査に対応。

### 5.3. 視覚的ページ並べ替えオーガナイザー
- サムネイル一覧でのドラッグ＆ドロップによるページ順序変更、不要ページの削除、白紙や他PDFからのページ挿入。

### 5.4. オフライン透かし (ウォーターマーク) ツール
- 斜め（45度）または水平のテキスト透かし合成（`DRAFT`, `CONFIDENTIAL`, `社外秘`, `SAMPLE` 等）と不透明度調整。

### 5.5. PDF パスワード保護と暗号化
- 業界標準のオフライン AES-256 暗号化による閲覧パスワードおよび権限パスワード（印刷・コピー制限）。

### 5.6. 外部PDFページ番号スタンプ (ベイツナンバリング)
- 既存のPDFファイルに対するページ番号の一括付与とプレフィックス設定。

## 6. リリース計画 バージョン 1.5.0 (エコシステムの最高峰と大規模文書性能)

**v1.5.0** マイルストーンは、Baku PDF エコシステムの集大成です：

### 6.1. 独立テンプレートパッケージ (.bakutpl)
- 自作テンプレートの単一配布ファイル `.bakutpl` への書き出しと、別端末での直接取り込み。

### 6.2. 拡張標準テンプレートコレクション
- 2段組学術ジャーナル書式および IEEE 論文集書式。
- 学生研究助成申請書、インターンシップ実習報告書、大学院学位論文提案書。
- 公的行政文書（通達、訓令、引渡書）。

### 6.3. 無限仮想DOMページレンダリング (500ページ以上対応)
- 画面表示領域 (*viewport*) の前後のページのみをDOM描画し、500ページ超の大規模原稿でも打鍵遅延 8ms 未満を維持。

### 6.4. 純粋 Rust ネイティブ PDF 出力エンジン
- Rust ライブラリ (`printpdf`/`lopdf`) による直接ベクター生成とフォントサブセット化により、ファイル容量を最大60%削減。

### 6.5. 完全適応型ダーク＆ライトテーマ
- WCAG AAA 適合の高コントラスト設計。白紙表示または夜間用反転表示の切り替え、OS設定との自動同期。

### 6.6. 集中執筆モード (Zen) および見開き2ページ表示
- 全インターフェースの一時非表示 (`F11` / `Cmd+Shift+F`) と、ワイド画面での横並び2ページ表示。

### 6.7. Word (.docx) インポートおよび標準形式エクスポート
- Word 文書のローカル構文解析と、`.docx`、プレーンテキスト (`.txt`)、科学的 Markdown (`.md`) への書き出し。

### 6.8. .baku ファイル形式仕様拡張 (v2.0)
- 高解像度画像の可逆圧縮バイナリコンテナ化と v1.0.0 文書との完全な後方互換性。

### 6.9. 定期自動保存とクラッシュ自動復元
- 60秒ごとのバックグラウンド保存、異常終了時のセッション復元、15/30/60分単位のローカル版管理。
