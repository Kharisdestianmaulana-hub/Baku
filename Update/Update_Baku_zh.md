# Baku PDF 更新路线图 (版本 v1.1.0 – v1.5.0)

本文档系统梳理了 **Baku PDF v1.0.0** 现已就绪的基线功能清单，并列明了从 **v1.1.0 至 v1.5.0** 按照版本划分的结构化技术路线图、性能调优和模块演进计划。各阶段发布均遵循量化评估与稳步测试原则，严格践行以下核心理念：

核心架构原则：
- **100% 纯本地离线 (Local-First)**: 严格在设备本地处理所有文档，无云端服务器依赖。
- **绝对隐私安全**: 无任何遥测上报、用户追踪或外部网络数据传输。
- **极致轻量资源开销**: 秒级瞬间启动，超低内存占用 (~50-80 MB RAM)。
- **极简平面 2D 设计**: 专注高效排版，去除冗余视觉干扰。
- **严苛排版标准兼容**: 深度契合高校学术学位论文规范及官方公文标准。

## 2. 版本 1.1.0 功能 (状态: 已完成并发布)

> [!NOTE]
> 版本 1.1.0 包含的全部功能已于 2026 年 10 月 16 日完整实现并正式发布。

**v1.1.0** 里程碑聚焦于多文档并行编撰体验与本地 PDF 文件高压缩比优化：

### 2.1. 多文档标签栏 (Multi-Document Tab Bar)
- **目标与核心收益**: 彻底摆脱在多份参考资料（如第一章草稿、导师修改批注、模板规范）之间反复进行系统窗口 `Alt+Tab` 切换的繁琐，在单一主窗口内无缝多开、实时切换并编辑多个 `.baku` 文档。
- **人体工学位置**: 精准置于 **Ribbon 功能区下方、水平标尺与编辑画布正上方**，纵向占用仅 30-32 px，充分利用屏幕宽度。
- **Flat 2D 视觉规范**: 紧凑型现代标签栏；当前激活标签为纯白背景 (`#FFFFFF`) 带有 2px 亮蓝顶部饰条 (`#2563EB`)；未激活标签为浅灰 (`#F3F2F1`)，长标题自动省略截断。
- **自适应横向滚动机制**: 1-5 份文档自适应平分显示；超过 5 份文档时支持触控板与滚轮横向丝滑滑动，并在溢出时自动浮现左右翻页控制箭头 `<` 与 `>`。
- **状态物理隔离与安全保障**: 每份标签页严格隔离各自的 Delta JSON 文档对象、滚动浏览位置、光标选区及独立撤销/重做历史 (`Ctrl+Z` / `Ctrl+Y`)。具有未保存更改指示蓝点，并在关闭前弹出确认对话框。
- **内存优化 (RAM Virtualization)**: 后台标签页以纯 JSON 形式驻留内存，无需渲染页面 DOM 节点。仅当前激活标签挂载 Quill 画布，内存始终稳定在 ~50-80 MB，毫无卡顿。
- **快捷键支持**: `Ctrl+Tab` 切换至下一标签，`Ctrl+Shift+Tab` 切换至上一标签，`Ctrl+W` 安全关闭当前标签。

### 2.2. 离线 PDF 文件压缩器 (Offline PDF Compressor)
- 由 Rust 原生驱动在本地对 PDF 文件进行精简优化，在保留清晰文字矢量的同时降低文件体积。
- 即时目标预设: 500 KB 以下（招考、招聘及公派留学上传标准）、1 MB 以下（高校论文盲审归档）、2 MB 以下及自定义 DPI 采样率 (150, 96, 72 DPI)。
- 保存前直观呈现压缩前后文件体积对比。

## 3. 版本发布规划 1.2.0 (学术规范与科学排版)

**v1.2.0** 里程碑专注于高校学术论文格式规范与高水准数学排版：

### 3.1. 论文双位置自动页码规则
- 自动化应用学术规范：每章第一页（含章标题）页码自动居于**底部居中**；本章后续连续页面自动切换至**右上角**。
- 分节独立重置页码起始值，不破坏前置章节编排。

### 3.2. 离线 KaTeX 数学公式排版引擎
- 100% 离线内置 KaTeX 引擎，支持行内公式 (`Inline Math`) 和独立公式块 (`Block Equation`)。
- 遵循章节编号公式右对齐编号：`(1.1)`, `(1.2)`。

### 3.3. 高级科学表格排版 (Booktabs 三线表)
- 单元格水平合并与垂直跨行合并。
- 学术规范无坚线设计：粗顶线、细表头下横线、粗底线。
- 数值列小数点自动对齐，表格跨页时长表头自动重复呈现。

### 3.4. 垂直标尺与高级段落缩进
- 水平标尺首行缩进滑块与悬挂缩进滑块（参考文献标准）。
- 左侧垂直标尺实时标定纸张高度，直观拖动调节上下页边距。

### 3.5. 离线拼写检查与文字规范指引
- 内置离线常用字词库，右键即时提供规范词替换建议，支持齐头尾排版的自动连字符断字。

### 3.6. 学术文档结构自动化生成
- 依据层级标题一键生成带点导引线 (*dot leaders*) 的动态目录。
- 实时同步页码的图表清单自动汇总。
- 离线引用与参考文献管理，支持 BibTeX (`.bib`) 导入及 GB/T 7714、APA 7、IEEE 格式。

## 4. 版本发布规划 1.3.0 (全跨平台分发与导航)

**v1.3.0** 里程碑面向 Windows 及 Linux 生态推进原生分发并加入文档结构导航：

### 4.1. Microsoft Windows 平台分发
- Windows 10/11 x64 与 ARM64 双架构 NSIS 安装引导包 (`.exe`)（开始菜单、快捷方式、`.baku` 扩展名注册）。
- 免安装独立便携版 (`Baku_Portable.exe`)，适合公共机房与离线实验环境。
- 正式提交微软官方软件包管理器 (`winget install Baku.BakuPDF`)。

### 4.2. Linux 平台分发
- 跨发行版独立 `AppImage` 单文件应用。
- 预声明完整依赖的原生 Debian/Ubuntu 安装包 (`.deb`)。
- 支持 Flatpak (Flathub) 及 Arch 用户软件仓库 (AUR: `baku-bin`)。

### 4.3. macOS 深度分发优化
- Homebrew Cask 终端命令便捷安装 (`brew install --cask baku-pdf`)。
- Apple Developer ID 官方签名与公证（Notarization），杜绝拦截警告。

### 4.4. 文档大纲导航侧边栏
- 左侧可折叠导航面板：标题大纲树（章与节快速跳转）、垂直页面微缩预览图、全文关键字查找替换结果列表。

## 5. 版本发布规划 1.4.0 (离线PDF实用工具与文档安全)

**v1.4.0** 里程碑引入专业级独立 PDF 处理模块与隐私合规脱敏：

### 5.1. 离线数字签名与电子签章
- 手写光标/触控笔签名，或导入透明底 PNG 印章拖拽定点覆盖。
- 多页固定坐标批量盖章，离线加盖日期印迹。

### 5.2. 文档元数据脱敏清洗器 (盲审专用)
- 导出发版前彻底抹除作者姓名、电脑硬件标识及修改时间轴，专门适配期刊与毕业论文的双盲同行评审 (*Blind Review*)。

### 5.3. 可视化页面重排整理器
- 缩略图网格界面，支持拖拽调整页面次序、单页或多页快速剔除、插入空白页或合并外部 PDF 页面。

### 5.4. 离线文本水印印鉴工具
- 45度倾斜或水平文本水印盖印（`草稿`, `绝密`, `内部资料`, `样本`），支持透明度与页码范围调整。

### 5.5. PDF 密码防护与加密
- 本地行业标准 AES-256 打开密码加密，权限密码限制打印与文本复制。

### 5.6. 外部 PDF 贝茨编排码 (Bates Numbering)
- 为第三方外来 PDF 批量加盖定制前缀的页码编号。

## 6. 版本发布规划 1.5.0 (生态系统里程碑之巅与海量文档性能)

**v1.5.0** 里程碑代表 Baku PDF 架构的集大成演进：

### 6.1. 独立便携式模板包 (.bakutpl)
- 自建模板一键导出为独立打包文件 `.bakutpl`，便于跨设备跨团队分享导入。

### 6.2. 拓展标准模板套件
- 国际双栏学术期刊格式及 IEEE 会议论文模板。
- 重点课题申报书、专业实习结业报告及硕博开题报告。
- 标准政府公文（通知、决定、会议纪要等官方公文版头）。

### 6.3. 无限虚拟 DOM 页面渲染引擎 (500+ 页超长篇幅)
- 仅动态装载视口 (*viewport*) 内外的页面元素，面对 500 页以上大部头论著，键盘输入延迟始终稳定在 8 ms 以内。

### 6.4. 纯 Rust 原生 PDF 矢量渲染核心
- 基于 Rust 底层库 (`printpdf`/`lopdf`) 原生绘制纯矢量字体，内嵌字体子集 (*Font Subsetting*)，体积瘦身达 60%。

### 6.5. 真正适应型深浅色外观主题
- 遵循 WCAG AAA 标准的高对比度深色模式，提供明亮纸张或夜间反色纸张，并支持跟随操作系统主题自动切换。

### 6.6. 极简专注写作模式 (Zen) 与双页并排视图
- 快捷键 (`F11` / `Cmd+Shift+F`) 瞬间隐藏所有界面控件；宽屏下并排展示两页阅读视图。

### 6.7. Word (.docx) 离线解析导入与多格式导出
- Rust 离线解析 Word 基础排版结构，并反向导出为 `.docx`、纯文本 (`.txt`) 及科学 Markdown (`.md`)。

### 6.8. .baku 文件规范升级 (v2.0)
- 内嵌无损压缩二进制附件容器（高清矢量插图），完美向下兼容 1.0.0 文件。

### 6.9. 定期自动备份与崩溃安全自愈
- 每 60 秒静默备份，异常断电启动时自动弹出恢复会话，支持 15/30/60 分钟历史快照回溯。
