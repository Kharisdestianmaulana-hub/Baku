# Baku PDF 发展路线图 (v1.1.0 – v1.5.0 阶梯式发布计划)

本文档梳理了 **Baku PDF v1.0.0** 现已交付的功能基线，并列出了自 **Baku PDF v1.1.0 至 v1.5.0 阶梯式逐步推进** 的新增功能、性能优化与模块扩展路线。本次更新聚焦于高级学术论文排版、离线 PDF 工具拓展、Windows/macOS/Linux 全平台分发以及超长文档的高性能秒级承载。

Baku PDF 的核心开发原则始终保持不变：
- **100% 离线优先 (Offline-First)**：所有排版与文档处理均在用户本地计算机上完成，不依赖任何云端服务器。
- **绝对隐私安全**：无任何遥测、无数据追踪分析、无外发网络传输。
- **极低系统资源占用**：秒速冷启动，运行时内存占用仅约 50–80 MB RAM。
- **极简 2D 扁平化设计**：界面干净直观，杜绝冗余视觉干扰。
- **严格规范化排版**：全面符合学术论文及正规行政公文的标准格式要求。

## 2. 文档编辑器与高级学术排版特性

### 2.1. 离线 KaTeX 数学公式与符号排版
- 100% 本地打包集成的 KaTeX 公式解析器，完全无需外部联网。
- 支持文中行内公式（Inline Math）及独立居中块级公式（Block Equation）。
- 依章节自动生成右对齐公式编号：`(1.1)`、`(1.2)` 等。
- 全面支持矩阵、微积分、线性代数及物理、化学标准符号。

### 2.2. 标尺能力扩展：段落缩进与垂直标尺
- 水平标尺新增专用缩进滑块：
  - **首行缩进游标**：定义段落首行缩进距离（如 1 厘米或 2 个字符）。
  - **悬挂缩进游标**：定义第二行及后续行缩进距离（APA、IEEE 参考文献标准）。
- 编辑画布左侧**垂直标尺**：
  - 精确测量页面实际物理高度（厘米）。
  - 支持拖动游标直接在画布上直观调整上边距与下边距。

### 2.3. 高级科技学术表格
- 单元格水平合并（Merge Columns）与垂直合并（Merge Rows）。
- 科技期刊规范三线表（Booktabs 风格）：无坚线，顶线与底线加粗，栏目线较细。
- 数值列依据小数点对齐。
- 跨页表格自动在后续页面重复表头行（Repeat Header Row）。
- 表格标题自动按章节顺序编号：`表 1.1: 实验数据汇总`。

### 2.4. 离线拼写检查与连字符排版
- 内置词典进行文字排印差错检测。
- 柔和的红色波浪线下划线标记未知词汇。
- 右键上下文菜单智能纠错建议。
- 两端对齐（Justify）下的自动音节连字符断字，避免单词间距过大变形。

## 3. 自动化化学术文档结构管理

### 3.1. 毕业论文双位置页码规则
- 自动化应用高校学位论文格式规范：
  - 每一章首页（包含章标题）页码强制居于**页脚中央**。
  - 该章后续各页页码自动转换为**页眉右侧**显示。
- 分节独立页码编排，前节与后节互不干扰。

### 3.2. 动态自动目录生成 (Auto TOC)
- 基于正文标题层级（一级标题、二级标题、三级标题）一键自动抽取目录。
- 标题文字与右侧页码之间自动填充引导点虚线（Dot Leaders）。
- 正文修改或分页调整后支持一键同步刷新全表。

### 3.3. 动态图表清单
- 自动持续追踪全文插图与表格标题说明。
- 实时生成与正文页码同步的插图清单与表格清单页面。

### 3.4. 离线文献引用与参考文献管理
- 手动录入文献或从 BibTeX (`.bib`) 与 RIS 文件直接导入。
- 自动按格式转换正文引用标注：APA 7版、IEEE、Harvard、Vancouver 格式。
- 文末自动生成按字母或出现顺序排列、符合标准悬挂缩进的参考文献列表。

## 4. 新增离线 PDF 扩展工具集

在现有的 4 大工具基础之上，v1.5 将新增 6 款纯离线本地工具：

### 4.1. 离线 PDF 文件压缩器
- 采用 Rust 本地高性能算法压缩 PDF 流数据，保证文字极度清晰。
- 快捷目标预设：小于 500 KB（政务求职入口标准）、小于 1 MB（高校学位系统标准）、小于 2 MB 以及手动 DPI 设置（150/96/72 DPI）。
- 保存前可直观对比压缩前后的精确文件体积。

### 4.2. 离线电子签名与骑缝印章
- 鼠标/手写笔屏幕手绘签名，或导入透明背景 PNG 格式签名图片。
- 支持在任意页面拖拽放置并实时预览签名大小。
- 多页文件按固定坐标批量盖章或骑缝章。
- 本地加盖时间戳与审批签章。

### 4.3. 密码保护与 AES-256 高强度加密
- 离线设置文档打开密码（User Password），采用业界标准的 AES-256 加密。
- 设置权限密码（Owner Password）：
  - 限制打印权限。
  - 限制文本复制与内容提取。
  - 限制批注添加与页面修改。
- 合法所有者的离线解密脱敏功能。

### 4.4. 页面可视化重排整理器
- 文档全页面缩略图网格排列视图。
- 拖拽页面自由交换顺序。
- 快捷删除单页或批量指定页码范围。
- 随时插入空白页或追加其他 PDF 文件的特定页面。

### 4.5. 贝茨编码与外部 PDF 页码套印
- 为第三方尚未编排页码的 PDF 快速补打页码。
- 位置自由配置：右上、右下或底部居中。
- 自定义前后缀文本（例如：`附件 第 1 页 共 10 页`、`编号 1`）。

### 4.6. 离线水印添加工具
- 支持斜向 45 度或横向文本水印。
- 内置常用字样：`草稿`、`机密`、`正式副本`、`SAMPLE`。
- 不透明度、文字尺寸、颜色以及作用页码范围灵活可调。

## 7. 核心架构、极限性能与长文档承载

### 7.1. 虚拟 DOM 页面渲染引擎
- 仅动态渲染当前屏幕视口内的纸张页面及前后 1–2 页缓冲区。
- 顺畅承载 500 页以上的超长学术专著或学位论文全书，内存占用平稳无剧烈抖动。
- 无论正文字数多寡，按键打字输入延迟保持在 8 毫秒以下。

### 7.2. 纯 Rust 原生矢量 PDF 导出引擎
- 核心 PDF 输出迁移至 Rust 原生底层引擎 (`printpdf` 与 `lopdf`)，辅助现有 WebView 打印。
- 导出全选文本无损矢量 PDF，文件大小缩减达 60%。
- 字体子集化（Font Subsetting）：仅将文档中实际出现的字形嵌入 PDF 中。

### 7.3. 60秒自动快照与异常中断恢复
- 每隔 60 秒自动向隔离的本地存储快照当前会话。
- 遇意外关机或程序崩溃，再次开启时立即弹出无损会话恢复窗口。
- 本地历史版本回溯，可快速恢复至 15、30 或 60 分钟前的编辑状态。

## 8. 用户界面、导航交互与无障碍设计

### 8.1. 侧边栏文档大纲与缩略图导航
- 编辑器左侧可折叠抽屉：显示各级标题树状大纲、页面缩略图以及查找替换的高亮匹配列表。

### 8.2. 自适应深色与浅色外观
- 严格遵循 WCAG AAA 标准的高对比度深色模式。
- 纸张显示选项：深色画布保持物理白纸，或开启夜间暗色反转护眼模式。
- 自动跟随操作系统外观设定无缝切换。

### 8.3. 无干扰沉浸写作禅模式 (Zen Mode)
- 快捷键 `F11` 或 `Cmd+Shift+F` 隐藏所有菜单与工具栏，专注于居中排版的白纸页面。

### 8.4. 跨页双联排版与高级比例预设
- 在超宽屏显示器上横向并排呈现两页内容（面对面版式）。

### 8.5. 多文档标签栏 (Multi-Document Tab Bar)
- **设计初衷与效率价值**：
  - 彻底免除在参考多个文件时频繁按 Alt+Tab / Cmd+` 切换操作系统的痛苦（如：第一章草稿、导师修改批注以及格式规范文件同时对照参考）。
  - 在同一主应用窗口内并行打开并随时编辑多份 `.baku` 文档。
- **符合人体工程学的布局位置**：
  - 明确布置在**功能区菜单（Ribbon Toolbar）下方、水平标尺与编辑画布上方**。
  - 严格遵循由上至下的自然操作层级：功能区选择工具 -> 标签栏切换文件上下文 -> 画布内编辑排版。
  - 充分利用窗口的整个横向宽度，避免在已有页码、字数和缩放滑块的底部状态栏内发生拥挤。
- **2D 扁平化视觉规范**：
  - 紧凑超薄的标签条（高度 30–32 px），最大化保留纵向写作视野。
  - **当前活动标签**：纯白背景（`#FFFFFF`）与标尺画布融为一体，顶部带有醒目的主色蓝线条（`#2563EB`），标题加粗，附带关闭按钮 `x` 与未保存修改状态标记。
  - **非活动标签**：中性低对比度浅灰（`#F3F2F1`），悬停过渡平滑。
  - 标签宽度超出时自动显示省略号（`text-overflow: ellipsis`），右端提供新建文档快捷按钮 `+`。
- **水平平滑滚动与导航机制**：
  - 打开 1 到 5 个文件时保持标签等比整齐排列。
  - 超过 5 个文件时支持触控板与鼠标滚轮顺滑横向滚动。
  - 出现内容溢出时，标签栏左右两端自动显现辅助滚动箭头 `<` 与 `>`。
- **独立状态隔离与数据可靠性**：
  - 每个标签页内部独立维护 Delta JSON 数据树、页面滚动坐标及光标位置，切换标签决不会跳回第1页。
  - 撤销（`Ctrl/Cmd+Z`）与重做（`Ctrl+Y` / `Cmd+Shift+Z`）历史栈按标签完全物理隔离。
  - 未保存文档带有蓝色圆点或星号提示，关闭未保存标签时主动弹出安全确认对话框。
- **本地极速内存控制**：
  - 标签虚拟化：处于后台的未激活标签仅作为轻量 JSON 数据保存在内存中，不会实例化庞大的 DOM 节点。

## 9. 格式互操作性与文件兼容性

### 9.1. 离线 Word (.docx) 导入解析
- 采用 Rust 纯本地解析器无损读取已有的 Word 文档，精准继承加粗、斜体、表格及段落格式。

### 9.2. 标准格式一键导出
- 导出为 Microsoft Word (`.docx`)、纯文本 (`.txt`) 以及学术 Markdown (`.md`)。

### 9.3. .baku 格式 2.0 规范升级
- 在内部 JSON 结构中引入无损压缩二进制附件容器，存储超高分辨率插图。
- 保持 100% 向后兼容性，v1.0.0 的旧版 `.baku` 文档在 v1.5 中开箱即用。

## 10. 文档安全性与元数据隐私清理

### 10.1. 元数据脱敏工具 (Metadata Sanitizer)
- 导出对外部署的正式 PDF 前自动擦除作者姓名、电脑设备名、本地路径以及编辑时间戳（学术双盲审必备）。

### 10.2. 只读防篡改锁定模式
- 对终稿文件进行锁定，避免意外触碰键盘修改正文。

## 11. 阶梯式版本发布规划与优先级矩阵 (v1.1.0 – v1.5.0)

为了让用户尽早获得稳定可用的新特性，避免因等待所有模块全部竣工而延宕过久，研发工作拆分为五个渐进式发布里程碑：

### 11.1. 阶梯式发布阶段计划

| 发行版本 | 阶段核心目标 | 包含功能模块 | 预期节奏 |
| :--- | :--- | :--- | :--- |
| **v1.1.0** | 文档标签与工作流提效 | 多文档标签栏（第 8.5 节）与离线 PDF 压缩器（第 4.1 节）。 | 下一邻近发布 |
| **v1.2.0** | 学术规范与科学排版 | 毕业论文双位置页码（第 3.1 节）、KaTeX 公式（第 2.1 节）、三线表 Booktabs（第 2.3 节）与垂直标尺（第 2.2 节）。 | 第二阶段 |
| **v1.3.0** | 全平台原生安装包分发 | Windows NSIS 安装包 (`.exe`) 与便携版（第 6.1 节）、Linux AppImage 与 Debian `.deb`（第 6.2 节）。 | 第三阶段 |
| **v1.4.0** | 离线实用工具与文档安全 | 电子签名与印章（第 4.2 节）、元数据隐私脱敏（第 10.1 节）、页面可视化重排（第 4.4 节）与水印（第 4.6 节）。 | 第四阶段 |
| **v1.5.0** | 生态巅峰里程碑与极限性能 | 便携模板包 `.bakutpl`（第 5.4 节）、500页长篇虚拟 DOM 渲染（第 7.1 节）、自适应深色主题（第 8.2 节）与 Word `.docx` 导入（第 9.1 节）。 | 阶段巅峰 |

### 11.2. 技术开发优先级矩阵

| 功能模块 | 目标技术层 | 目标版本 | 优先级 | 复杂度评估 |
| :--- | :--- | :--- | :--- | :--- |
| 多文档标签栏 (Multi-Document Tabs) | 前端编辑器与状态机 | v1.1.0 | 最高 | 中等 |
| 离线 PDF 文件压缩器 | Rust 后端 (`lopdf` / `image`) | v1.1.0 | 最高 | 中等 |
| 毕业论文双位置页码规则 | 前端纸张排版引擎 | v1.2.0 | 高 | 中等 |
| 离线 KaTeX 数学公式 | 前端语法解析引擎 | v1.2.0 | 高 | 较低 |
| 垂直标尺与段落缩进游标 | 前端标尺组件 | v1.2.0 | 中 | 中等 |
| 规范科技三线表 (Booktabs) | 前端纸张排版引擎 | v1.2.0 | 中 | 中等 |
| Windows (.exe) 与 Linux (AppImage) 安装包 | Tauri 打包与 CI 流程 | v1.3.0 | 最高 | 中等 |
| 侧边栏大纲与缩略图导航 | 前端 UI 与虚拟 DOM | v1.3.0 | 高 | 中等 |
| 离线电子签名与骑缝印章 | Rust 后端与画布图层 | v1.4.0 | 中 | 中等 |
| 元数据隐私脱敏 (双盲审) | Rust 后端与 PDF 管道 | v1.4.0 | 中 | 较低 |
| 页面可视化重排整理器 | 前端 UI 与 Rust 后端 | v1.4.0 | 中 | 中等 |
| 自适应深色外观 | CSS 主题引擎 | v1.5.0 | 中 | 较低 |
| 独立模板包导出导入 (.bakutpl) | 前端存储与 JSON 解析 | v1.5.0 | 中 | 较低 |
| 虚拟 DOM 页面渲染 (500+页) | 前端 DOM 虚拟化引擎 | v1.5.0 | 高 | 较高 |
| 离线 Word (.docx) 导入解析 | Rust DOCX 解析器 | v1.5.0 / 未来 | 未来规划 | 较高 |
