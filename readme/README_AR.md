## حول Baku PDF

يُعد Baku PDF معالج نصوص مكتبي حديث صُمم خصيصاً لكتابة الأطروحات والرسائل الجامعية والأوراق البحثية والمراسلات الرسمية وفقاً لمعايير تنسيق وهوامش دقيقة. استناداً إلى فلسفة **Local-First**، تتم جميع عمليات معالجة النصوص وعرض الصفحات وتحرير ملفات PDF محلياً بالكامل على جهازك دون الحاجة إلى خوادم خارجية أو تتبع أو اشتراكات سحابية.

تم تطوير التطبيق باستخدام **Tauri** و **Rust** مع واجهة أمامية نقية، مما يجعله خفيفاً للغاية (استهلاك ذاكرة RAM يتراوح بين 50 و 80 ميغابايت فقط) مع إقلاع فوري وتجاوب سريع يخلو من البطء المعهود في محررات النصوص المبنية على Electron.

## المميزات الرئيسية

1. **شاشة رئيسية سريعة بنمط Word**:
   - بدء مستند فارغ بنقرة واحدة.
   - فتح مباشر لملفات الصيغة الأصلية `.baku`.
   - بطاقات مصغرة لنماذج المستندات توضح حدود التنسيق والبيانات الرسمية.
   - سجل المستندات الأخيرة والوصول السريع لمعرض النماذج.

2. **معرض النماذج القياسية وصانع النماذج**:
   - نماذج معتمدة للأطروحات، والأوراق العلمية، والخطابات الرسمية، والسير الذاتية المتوافقة مع أنظمة ATS.
   - تصفح حسب الفئات وبحث فوري بالكلمات المفتاحية.
   - قفل المعايير الصارم لمنع التعديل غير المقصود على الهوامش وأحجام الصفحات.
   - تصدير واستيراد ملفات النماذج المستقلة بصيغة `.baku`.

3. **شريط تبويب المستندات المتعددة (جديد في v1.1.0)**:
   - فتح وتحرير والتبديل بين عدة مستندات `.baku` بالتوازي في نافذة واحدة.
   - سجل تراجع/إعادة مستقل وعزل كامل لحالة المستند في الذاكرة.
   - مؤشر نقطي للتغييرات غير المحفوظة، زر تبويب جديد (+)، زر إغلاق (x)، وتمرير أفقي.
   - دعم كامل لاختصارات لوحة المفاتيح (`Option/Alt + [1-9]`, `Ctrl + Tab`, `Cmd/Ctrl + W`).

4. **نظام ذكي لتعدد الصفحات والأقسام**:
   - فواصل صفحات فورية وسلسة (Ctrl/Cmd + Enter) بمعدل 60 إطاراً في الثانية.
   - فواصل أقسام (Ctrl/Cmd + Shift + Enter) لإعادة ترقيم الفصول وتغيير الترويسات بين الأبواب.
   - أنماط ترقيم متعددة: أرقام عربية، وأرقام رومانية، وأحرف هجائية.
   - خيار تخصيص الصفحة الأولى لإخفاء الترقيم من صفحات الغلاف الرسمية.

5. **مسطرة بصرية تفاعلية**:
   - مسطرة أفقية بوحدات المليمتر والسنتيمتر والبوصة.
   - مؤشرات سحب قابلة للتعديل: إزاحة السطر الأول، الإزاحة اليسرى، والهامش الأيمن.
   - مزامنة فورية ومباشرة مع الفقرة النشطة في المحرر.

6. **تنسيقات طباعية دقيقة**:
   - أنماط سريعة: عادي، عنوان المستند، عنوان فرعي، العناوين 1 و 2 و 3، اقتباس، والرموز البرمجية.
   - تحكم دقيق في حجم الخط (من 8pt إلى 72pt)، وتباعد الأسطر (1.0، 1.15، 1.5، 2.0)، ولوحات الألوان.
   - هوامش أكاديمية محددة مسبقاً (4-4-3-3 سم، 4-3-4-3 سم، 3-3-3-3 سم، 2.54 سم) ومقاسات الورق (A4، Folio/F4، Letter، Legal).

7. **أدوات تحرير متكاملة**:
   - **تغيير حالة الأحرف**: حالة الجملة، أحرف صغيرة، أحرف كبيرة، وتبديل الحالة.
   - **إحصائيات فورية للمستند**: عدد الكلمات، والأحرف، والفقرات، والوقت التقديري للقراءة.
   - **محرر جداول تفاعلي**: إضافة الجداول والتحكم بالصفوف والأعمدة ومحاذاة الخلايا.
   - **إدارة الصور**: إدراج محلي ومحاذاة وتغيير الأبعاد مع الحفاظ على النسب.
   - **محدد الرموز الخاصة**: إدراج الرموز الرياضية والطباعية بضغطة زر.

8. **تصدير WYSIWYG مطابق للشاشة وطباعة أصلية**:
   - تصدير ملفات PDF بدقة متطابقة تماماً مع ما تراه على مساحة العمل.
   - مربع حوار طباعة متصل مباشرة بأنظمة الطباعة المحلية في نظام التشغيل.

9. **تمرير سلس لساحة العمل وشريط جانبي مرن (جديد في v1.1.0)**:
   - تمرير ناعم ومستمر لساحة العمل بدون تقطيع.
   - تخطيط عمودي مريح للشريط الجانبي المطوي ونقل زر الإعدادات إلى أسفل اليسار.
   - حفظ حالة طي الشريط الجانبي تلقائياً.

## أدوات PDF الإضافية (تعمل 100% بدون إنترنت)

يحتوي Baku PDF على أدوات مستقلة للتعامل مع ملفات PDF دون الحاجة إلى الاتصال بالشبكة:
- **ضغط ملفات PDF (Compress PDF) [جديد في v1.1.0]**: تقليل حجم ملفات PDF محلياً عبر 3 أنماط مسبقة (قياسي، أقصى، خفيف) دون إنترنت.
- **دمج ملفات PDF (Merge PDF)**: جمع ملفين أو أكثر في مستند واحد بترتيب مرن.
- **تقسيم PDF (Split PDF)**: استخراج صفحات معينة أو نطاقات محددة (مثل 1-3، 5، 8-10).
- **تدوير الصفحات (Rotate PDF)**: تصحيح زوايا الصفحات المائلة بمقدار 90 أو 180 أو 270 درجة.
- **تحويل الصور إلى PDF (Images to PDF)**: تحويل مجموعات الصور JPG/PNG إلى ملف PDF منظم وجاهز للطباعة.

## خارطة طريق الإصدارات القادمة (v1.2.0 – v1.5.0)

مع الإطلاق الرسمي لإصدار **Baku PDF v1.1.0** (الذي أضاف شريط تبويب المستندات المتعددة وضاغط ملفات PDF دون اتصال)، تركز خارطة الطريق على المراحل اللاحقة من v1.2.0 إلى v1.5.0:

- **مثبتات المنصات المتعددة**: مثبت NSIS لنظام Windows (`.exe`)، ونسخة محمولة مستقلة، وحزم Linux بصيغتي `AppImage` و Debian `.deb`.
- **ترقيم صفحات الأطروحات المزدوج**: ترقيم تلقائي في أسفل الوسط لصفحة بداية الفصل وأعلى اليمين للصفحات اللاحقة.
- **أدوات علمية متقدمة دون اتصال**: معادلات KaTeX، وجداول أكاديمية بنمط booktabs، وإعادة ترتيب الصفحات بصرياً، والتوقيع الرقمي.

## البنية البرمجية والتقنيات المستخدمة

- **الواجهة الخلفية**: Rust 2021 مع إطار عمل Tauri v1.6.
- **محرك معالجة PDF**: مكتبة `lopdf` v0.31 للتعامل المباشر مع هياكل الملفات ومكتبة `printpdf` v0.7 لتوليد الصفحات.
- **الواجهة الأمامية**: HTML5 و CSS3 نقي و Vanilla JavaScript ES6+ دون أطر عمل ثقيلة.
- **نواة المحرر**: إصدار مخصص من Quill.js 2.0 يدعم فواصل الصفحات والأقسام.
- **صيغة الحفظ**: صيغة JSON مهيكلة `.baku` تعتمد الكتابة الذرية (*atomic write*) لحماية البيانات من التلف.
- **تسريع الرسوميات**: طبقات صفحات مركبة ومعالجة عبر وحدة معالجة الرسوميات GPU.

## متطلبات التشغيل والتثبيت

### المتطلبات المسبقة
- Node.js (الإصدار 16 أو أحدث)
- Rust و Cargo (أحدث إصدار مستقر)
- بيئة بناء Tauri الخاصة بنظام التشغيل المستخدم (macOS أو Windows أو Linux)

### خطوات التشغيل والتطوير
1. استنساخ المستودع:
   ```bash
   git clone https://github.com/Kharisdestianmaulana-hub/Baku.git
   cd Baku
   ```

2. تثبيت الحزم البرمجية:
   ```bash
   npm install
   ```

3. التشغيل في وضع التطوير:
   ```bash
   npm run tauri dev
   ```

4. بناء النسخة الإنتاجية والتنفيذية:
   ```bash
   npm run tauri build
   ```
