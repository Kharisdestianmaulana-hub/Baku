## О Baku PDF

Baku PDF — это современный текстовый процессор для настольных компьютеров, созданный специально для подготовки академических статей, дипломных и магистерских диссертаций, а также деловых официальных писем в строгом соответствии с нормативными стандартами оформления. Приложение следует философии **local-first**: обработка текста, верстка страниц и работа с PDF выполняются на 100% локально на вашем компьютере без внешних серверов, телеметрии и подписок.

Благодаря связке **Tauri** и **Rust** со сверхлегким Vanilla JS-интерфейсом, Baku PDF потребляет минимум оперативной памяти (всего ~50–80 МБ), запускается мгновенно и не имеет задержек ввода, свойственных приложениям на базе Electron.

## Ключевые Возможности

1. **Быстрый Главный Экран в Стиле Word**:
   - Мгновенное создание чистого документа.
   - Прямое открытие файлов формата `.baku`.
   - Наглядные миниатюры шаблонов с разметкой полей и официальными бейджами.
   - Список недавних документов и доступ к полной галерее.

2. **Галерея Стандартных Шаблонов и Конструктор**:
   - Готовые шаблоны для диссертаций, курсовых, отчетов по лабораторным работам, деловых писем и резюме для ATS-систем.
   - Поиск по ключевым словам и категориям.
   - Блокировка стандартов (*Strict Standard Lock*) для предотвращения случайного изменения полей и формата листа.
   - Экспорт и импорт автономных файлов шаблонов `.baku`.

3. **Панель Вкладок Мультидокументов (Новое в v1.1.0)**:
   - Параллельное открытие, редактирование и переключение между несколькими документами `.baku` в одном окне.
   - Независимая история Undo/Redo и изолированное состояние документа в оперативной памяти.
   - Индикатор несохраненных изменений (точка), кнопка новой вкладки (+), кнопка закрытия (x) и горизонтальная прокрутка.
   - Полная поддержка горячих клавиш (`Option/Alt + [1-9]`, `Ctrl + Tab`, `Cmd/Ctrl + W`).

4. **Многостраничный и Многосекционный Движок**:
   - Разрыв страницы (*Page Break*, Ctrl/Cmd + Enter) на скорости 60 FPS без задержек.
   - Разрыв раздела (*Section Break*, Ctrl/Cmd + Shift + Enter) для перезапуска нумерации или изменения колонтитулов между главами.
   - Различные форматы нумерации: арабские цифры, римские цифры (строчные и заглавные), буквы.
   - Особый колонтитул для первой страницы титульного листа.

5. **Интерактивная Визуальная Линейка**:
   - Горизонтальная шкала в миллиметрах, сантиметрах и дюймах.
   - Три интерактивных маркера: отступ первой строки, левый отступ и правое поле.
   - Мгновенная синхронизация с активным абзацем.

6. **Точная Типографика и Стили Оформления**:
   - Быстрые стили: Обычный, Заголовок документа, Подзаголовок, Заголовки 1–3, Цитата и Моноширинный код.
   - Выбор размера шрифта (от 8pt до 72pt), межстрочного интервала (1.0, 1.15, 1.5, 2.0) и палитры цветов.
   - Стандартные академические поля (4-4-3-3 см, 4-3-4-3 см, 3-3-3-3 см, 2.54 см) и форматы бумаги (A4, Folio/F4, Letter, Legal).

7. **Встроенные Инструменты Редактирования**:
   - **Регистр Символов**: Как в предложениях, все строчные, ВСЕ ПРОПИСНЫЕ, Начинать С Прописных и Инвертировать.
   - **Статистика в Реальном Времени**: Подсчет слов, символов (с пробелами и без), абзацев и расчетного времени чтения.
   - **Редактор Таблиц**: Сетка добавления и всплывающая панель управления строками и столбцами.
   - **Работа с Изображениями**: Вставка, выравнивание, пропорциональное масштабирование и безопасное удаление.
   - **Таблица Символов**: Диалог вставки типографических и математических знаков.

8. **WYSIWYG-Экспорт в PDF и Нативная Печать**:
   - Генерация PDF пиксель-в-пиксель точно по границам рабочего листа.
   - Диалог печати, подключенный напрямую к системным принтерам.

9. **Плавная Прокрутка Холста и Гибкая Боковая Панель (Новое в v1.1.0)**:
   - Плавная интерполяция прокрутки холста без микрорывков.
   - Эргономичное вертикальное расположение свернутой боковой панели и перенос кнопки настроек в нижний левый угол.
   - Сохранение состояния свернутой боковой панели.

## Офлайн-Инструменты PDF (100% Локально)

Baku PDF содержит автономные модули для работы с PDF без интернета:
- **Сжатие PDF (Compress PDF) [Новое в v1.1.0]**: Уменьшение размера файлов PDF локально с 3 профилями сжатия (Стандартный, Максимальный, Легкий) без отправки на серверы.
- **Объединить PDF (Merge PDF)**: Сборка нескольких файлов в один с возможностью настройки порядка.
- **Разделить PDF (Split PDF)**: Извлечение указанных страниц или диапазонов (например: 1-3, 5, 8-10).
- **Повернуть PDF (Rotate PDF)**: Корректировка ориентации страниц на 90, 180 или 270 градусов.
- **Изображения в PDF (Images to PDF)**: Преобразование изображений JPG/PNG в готовый к печати документ PDF.

## План Будущих Релизов (v1.2.0 – v1.5.0)

С официальным выходом **Baku PDF v1.1.0** (включающим панель вкладок мультидокументов и офлайн-компрессор PDF) наш план разработки сосредоточен на следующих этапах от v1.2.0 до v1.5.0:

- **Кроссплатформенные Установщики**: Установщик NSIS для Windows (`.exe`), автономная портативная версия, а также пакеты Linux `AppImage` и Debian `.deb`.
- **Двойная Нумерация Страниц для Диссертаций**: Автоматическое размещение номера снизу по центру для заглавных страниц глав и сверху справа для остальных страниц.
- **Продвинутые Офлайн-Инструменты**: Формулы KaTeX, таблицы в академическом стиле booktabs, визуальная сортировка страниц и электронные подписи.

## Архитектура и Стек Технологий

- **Бэкенд**: Rust 2021 и фреймворк Tauri v1.6.
- **Движок PDF и ввод/вывод**: `lopdf` v0.31 для низкоуровневых операций и `printpdf` v0.7 для сборки страниц.
- **Фронтенд**: HTML5, чистый CSS3 и Vanilla JavaScript ES6+ (без тяжелых библиотек).
- **Ядро редактора**: Модифицированный Quill.js 2.0 с поддержкой разрывов страниц и разделов.
- **Формат хранения**: Файлы JSON `.baku` с механизмом атомарной записи (*atomic write*).
- **Графическое ускорение**: Композитные слои страниц с кэшированием на GPU.

## Системные Требования и Установка

### Предварительные Требования
- Node.js (версии 16 или выше)
- Rust и Cargo (актуальный стабильный канал)
- Инструменты сборки Tauri для вашей операционной системы (macOS, Windows или Linux)

### Запуск и Сборка
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Kharisdestianmaulana-hub/Baku.git
   cd Baku
   ```

2. Установить зависимости:
   ```bash
   npm install
   ```

3. Запустить режим разработки:
   ```bash
   npm run tauri dev
   ```

4. Собрать релизные пакеты:
   ```bash
   npm run tauri build
   ```
